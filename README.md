# Programa-o-Orientada-a-Objetos-I
Repositório da disciplina de **Programação Orientada a Objetos I**, contendo exercícios, exemplos e projetos desenvolvidos durante o curso. O objetivo é aplicar os conceitos fundamentais de POO, como classes, objetos, encapsulamento, herança, polimorfismo e abstração, por meio de atividades práticas.
